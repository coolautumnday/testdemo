# AI 网页生成器

> 
> 基于智谱大模型的本地多智能体网页生成工具，浏览器端运行，无需后端服务。输入需求即可自动完成需求分析、代码生成、代码评审、自动缺陷修复，实时预览可交互网页，支持导出完整 HTML 文件。

## ✨ 功能特性

1. **多智能体协同工作**
   - 📋 产品 Agent：解析用户需求，输出结构化需求分析报告
   - 👨‍💻 工程师 Agent：根据需求生成完整内嵌式 HTML 网页
   - 🔍 测试 Agent：代码评审，检测 JS 语法、边界、NaN 渲染、交互风险
   - ✅ 产品复核 Agent：核对实现是否匹配原始需求，识别业务缺陷
2. **简易模式**：跳过产品需求分析，直接生成代码，减少超时
3. **自动修复机制**：检测到中 / 高风险 Bug 自动循环修复（最多 3 轮）
4. **三栏布局**
   - 左侧：对话聊天面板，输入需求，查看智能体输出
   - 中间：代码编辑器，可手动修改 HTML 代码
   - 右侧：实时可交互 iframe 预览，自动捕获页面 JS 运行报错、NaN 告警
5. **账号登录注册**：账号信息本地浏览器`localStorage`存储
6. **API Key 本地存储**：智谱 API 密钥仅保存在浏览器本地，不会上传第三方服务器
7. **会话持久化**：对话、生成代码本地保存，刷新页面不丢失
8. **导出 HTML**：一键下载生成的完整网页文件
9. **手动停止任务**：生成过程随时终止网络请求与打字输出
10. **独立代码评审**：对编辑器内已有 HTML 执行 AI 代码评审

## 📋 环境与依赖

- 仅需要现代浏览器（Chrome、Edge、Firefox 等），**不需要安装 Node、不需要后端服务器**
- 网络：需要可以访问智谱开放平台接口 `https://open.bigmodel.cn/api/paas/v4/chat/completions`
- 模型依赖：`glm‑4‑flash`、`glm‑4v‑flash`，需要在智谱开放平台开通模型权限
- 前端 CDN 依赖：TailwindCSS、Font‑Awesome（页面加载时在线拉取）

> 
> ⚠️ 全部数据：用户账号、会话记录、API Key 均存储浏览器`localStorage`，清除浏览器缓存会丢失本地数据。

## 🚀 快速开始

### 1. 获取智谱 API Key

1. 前往 [智谱 AI 开放平台](https://open.bigmodel.cn/) 注册账号
2. 创建 API 密钥，复制你的 `API Key`
3. 确认账户已经开通 `glm‑4‑flash` 模型调用权限，账户有余额

### 2. 运行项目

1. 将全部代码保存为 `index.html`
2. 使用浏览器直接打开该 HTML 文件（双击即可，不要使用本地文件服务以外的复杂环境）
3. **第一步：注册账号**，输入用户名密码完成注册，然后登录
4. 登录后弹出 API‑Key 配置弹窗，粘贴刚才复制的智谱 Key，点击验证并进入应用
5. 验证成功即可使用。

> 
> 如果弹窗没有自动弹出，可以点击顶部栏【配置 API‑Key】按钮手动输入密钥。

## 📖 使用教程

### 基础生成网页

1. 在左侧输入框输入你的网页需求，示例：
   - `做一个番茄钟网页，支持计时、暂停重置，简约蓝色主题`
   - `做一个简单待办事项清单，可以新增删除待办`
2. 可选勾选**简易模式**：适合简单页面，跳过产品分析，降低超时概率
3. 点击【发送，让 AI 生成应用】
4. 左侧会看到各个智能体执行日志，中间输出完整 HTML，右侧实时预览网页效果
5. 系统自动执行测试评审、产品复核，检测到中高风险问题自动修复，最多执行 3 轮修复

### 手动修改代码

中间编辑器可以直接修改 HTML 代码，修改完成后右侧预览会自动刷新。

### AI 代码评审

点击【AI 代码评审】，针对编辑器中现有代码执行独立测试评审，输出风险报告。

### 导出网页

点击【导出 HTML】，下载 `output.html` 文件，该文件可以脱离本工具，直接浏览器打开运行。

### 其他操作

- **新建会话**：清空当前对话与生成代码，开启全新任务，建议会话消息多时新建，减少模型上下文过长导致的格式错乱、超时
- **清空对话**：只清空聊天记录，保留生成的代码
- **停止**：任务运行时，终止当前所有网络请求与输出
- **清除 Key**：清除本地保存的智谱 API 密钥
- **退出登录**：退出账号，会话清空，密钥保留

## ⚠️ 重要注意事项与限制

1. **浏览器本地运行，密钥保存在本地，不要把你的 index.html 分享给其他人，避免泄露 API Key**。
2. 模型输出有可能截断：大网页场景，大模型输出被截断会造成 HTML 不完整，会有警告提示，建议简化需求或者新建会话重试。
3. 最大自动修复轮次为 3 轮，修复失败后需要人工修改编辑器内代码。
4. 会话消息有上限（30 条），上下文过多会容易超时、输出格式错乱，建议勤新建会话。
5. 预览 iframe 开启`sandbox`沙箱，部分高级网页能力会受限。
6. JS 语法预检仅做静态语法检查，无法保证业务逻辑完全正确，务必查看预览效果。
7. 浏览器`localStorage`容量有限，复杂长会话可能触发存储超限，会出现提示。
8. 网络超时时间设置 5 分钟，复杂页面生成时间较长，耐心等待。

## 🔧 自定义配置

打开`index.html`，找到`CONST`常量对象，可以修改参数：

```
const CONST = {
  LLM_BASE_URL: "https://open.bigmodel.cn/api/paas/v4/chat/completions",
  MODEL_CODE: "glm-4-flash",       // 代码生成模型
  MODEL_DRAW: "glm-4v-flash",
  LLM_TEMPERATURE: 0.7,            // 模型随机性
  LLM_TIMEOUT_MS: 300000,          // 请求超时毫秒
  MAX_FIX_RETRY: 3,                // 最大自动修复轮次
  MAX_SESSION_MSG_COUNT: 30        // 会话消息最大条数
};
```

可以替换模型地址、更换模型、调整最大修复次数、超时时间。

## 🐛 常见问题

### 1. API Key 校验失败

- 确认 Key 复制完整，不要带多余空格换行
- 确认账号余额充足，开通对应模型权限
- 确认网络可以访问智谱开放平台接口

### 2. 生成输出被截断

- 需求拆分，把复杂网页拆分成更小需求
- 勾选简易模式，减少上下文长度
- 新建会话重新生成

### 3. 预览页面报错

- 查看左侧对话面板，iframe 捕获的运行时错误会打印到聊天窗口
- 查看代码评审报告，根据报告修改中间编辑器代码

### 4. 模型返回格式错乱

上下文消息过多，点击新建会话，重新发起请求。
