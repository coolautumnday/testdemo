# AI 网页生成器

> 
> 基于智谱大模型的多智能体前端网页生成工具，浏览器端直接运行，输入需求即可自动生成、评审、修复完整可交互 HTML 网页。

## ✨ 功能特性

1. **多智能体协作流程**
   - 📋 产品 Agent：拆解用户需求，输出结构化需求分析报告
   - 👨‍💻 工程师 Agent：根据需求生成完整内嵌 CSS/JS 的 HTML 页面
   - 🔍 测试 Agent：代码评审，检测 JS 边界、NaN、异常、交互风险
   - ✅ 产品复核 Agent：校验实现是否匹配原始需求，输出修复清单
2. **自动缺陷修复**：检测到中 / 高风险 bug 时自动循环修复（最大 3 轮）
3. **简易模式**：跳过产品需求分析，直接生成代码，减少超时
4. **三栏布局界面**
   - 左侧：对话交互面板，输入需求、查看智能体输出
   - 中间：代码编辑器，可手动修改 HTML 源码
   - 右侧：实时可交互 iframe 预览，自动监听页面运行报错、NaN 渲染告警
5. **本地存储**
   - API Key 仅保存在浏览器`localStorage`，不会上传第三方服务器
   - 会话自动持久保存，刷新页面不丢失对话与生成代码
6. **辅助能力**
   - 一键导出生成的 HTML 文件
   - 手动触发 AI 代码评审
   - 停止生成、新建会话、清空对话、清除密钥
   - JS 语法预校验、预览页面运行时错误捕获

## 🚀 快速使用

### 1. 获取代码

把项目完整代码保存为 `index.html`。

### 2. 打开运行

直接使用浏览器打开 `index.html`，**不需要后端服务，纯前端单文件运行**。

### 3. 配置智谱 API‑Key

1. 首次打开弹出密钥输入弹窗；
2. 填入你的智谱平台 API Key，点击「验证并进入应用」；

> 
> 密钥仅存储在浏览器本地 localStorage，不会发送到其他地址。

### 4. 生成网页

1. 在左侧输入框描述网页需求，例如：
   - `做一个番茄钟网页，支持计时、暂停重置`
   - `写一个简易计算器页面`
2. 可选勾选「简易模式」跳过产品分析；
3. 点击发送，多智能体自动完成需求拆解→生成代码→评审→自动修复；
4. 中间面板查看生成 HTML，右侧实时预览交互效果；
5. 可以手动修改编辑器代码，预览会实时更新；
6. 点击`导出HTML`把结果保存成本地文件。

## ⚙️ 内置配置说明

代码顶部 `CONST` 对象可以修改参数：

```
const CONST = {
  LLM_BASE_URL: "https://open.bigmodel.cn/api/paas/v4/chat/completions",
  MODEL_CODE: "glm-4-flash",      //代码生成模型
  MODEL_DRAW: "glm-4v-flash",     //绘图相关模型
  LLM_TEMPERATURE: 0.7,
  LLM_TIMEOUT_MS: 300000,         //请求超时毫秒
  MAX_FIX_RETRY: 3,               //最大自动修复轮次
  MAX_SESSION_MSG_COUNT: 30       //会话最大消息数，防止存储溢出
};
```

## 📌 重要限制与注意事项

1. **网络要求**：浏览器需要可以访问智谱开放 API 接口；
2. **模型权限**：你的智谱账号需要开通对应模型调用权限，有足够额度；
3. **安全沙箱**：预览 iframe 设置`sandbox="allow-scripts"`，禁止外部资源加载；不支持外部 CDN、外部图片；图形仅允许 CSS div 绘制；
4. **存储限制**：会话保存在浏览器 localStorage，消息过多会自动截断，建议复杂项目多新建会话；
5. **超时问题**：复杂网页生成、多轮评审修复耗时较长，如果超时，建议开启简易模式，或者拆分需求简化；
6. 自动修复不能保证 100% 解决所有 bug，复杂场景建议手动修改代码。

## 🔧 按钮说明

表格

| 按钮 | 功能 |
| --- | --- |
| 新建会话 | 终止当前任务，清空全部会话、代码、预览 |
| 清空对话 | 只清空聊天记录，保留生成的代码 |
| 清除 Key | 删除本地保存的 API 密钥，回到密钥配置弹窗 |
| 停止 | 中断当前 AI 网络请求与渲染 |
| AI 代码评审 | 使用测试 Agent 对编辑器内现有代码做评审 |
| 导出 HTML | 下载中间编辑器内完整 HTML 为本地文件 |

## 🛡️ 安全说明

1. API Key 只存于浏览器本地 localStorage，不会上传到其他服务器；
2. 预览 iframe 做沙箱限制，移除`allow-same-origin`避免密钥泄露风险；
3. 页面会捕获预览内部 JS 报错、Promise 异常、DOM 渲染 NaN 告警并反馈在聊天面板。
